## 1. EXECUTIVE SUMMARY

This skill encodes the visual language of Russian Constructivism (1920s avant-garde) and Brutalist architecture (1950s–1970s). It covers the bold geometric abstraction of Rodchenko and El Lissitzky, the red-black-white propaganda palette, photomontage techniques, diagonal dynamism, and the raw concrete monumentalism of Brutalism — from Le Corbusier's béton brut to the Smithsons' New Brutalism.

When this skill is active, the agent should:
- Use Constructivist-specific composition terms (diagonal dynamism, photomontage, agitprop)
- Apply the red-black-white symbolic palette
- Reference Brutalist material vocabulary (béton brut, exposed aggregate, formwork texture)
- Build scenes using monumental scale and human insignificance
- Understand the emotional register: urgency, collective power, raw honesty, imposing scale

## 2. SOVIET CONSTRUCTIVISM: THE AVANT-GARDE LANGUAGE

Constructivism was not art for art's sake — it was **art as communication weapon**. [^62^] [^67^] [^73^] [^74^] [^75^]

### Core Principles

| Principle | Description | Prompt Vocabulary |
|-----------|-------------|-----------------|
| **Art as Tool** | Design serves social purpose; aesthetics are secondary to message | "art as tool", "message-driven design", "functional aesthetics" |
| **Geometric Abstraction** | Circles, squares, lines, and photomontage fragments create engineered compositions | "geometric abstraction", "engineered composition", "constructivist geometry" |
| **Diagonal Dynamism** | Strong diagonal lines create movement, urgency, and revolutionary momentum | "diagonal dynamism", "aggressive diagonal", "forward momentum" |
| **Photomontage** | Cut photographs combined with typography for direct, powerful messaging | "photomontage", "cut-photo composition", "fragmented reality" |
| **Typographic Monument** | Text is not decoration — it is structural, bold, all-caps, multi-sized | "typographic monument", "word architecture", "bold structural type" |
| **Maximum Contrast, Minimum Colors** | Red, black, white (and occasionally grey) — no decorative palette | "high contrast minimal palette", "red black white", "symbolic color reduction" |

### The Red Wedge (El Lissitzky)
El Lissitzky's 1919 poster *Beat the Whites with the Red Wedge* is the quintessential Constructivist work: [^62^] [^73^]
- **Red triangle** = Bolshevik revolutionaries penetrating White army defenses
- **Black and white circles** = opposing forces
- **No text needed** — geometry tells the story
- **Dynamic tension** — shapes push against each other

**Prompt Translation:**
> "red wedge penetrating white circle, geometric political abstraction, dynamic shape tension, El Lissitzky composition, symbolic geometry telling narrative"

### Typography Rules

| Rule | Description | Prompt Terms |
|------|-------------|------------|
| **Sans-Serif Only** | No decorative serifs; type must be functional and modern | "sans-serif monument", "geometric type", "functional lettering" |
| **All Caps** | Lowercase is weak; uppercase commands attention | "all-caps typography", "monumental lettering", "shouting text" |
| **Mixed Sizes** | One word massive, another tiny — creates visual rhythm and hierarchy | "mixed-size typography", "hierarchical scale", "dynamic type rhythm" |
| **Type as Image** | Letters become shapes, not just readable symbols | "type as image", "letterform architecture", "text as visual element" |
| **Diagonal Setting** | Text follows diagonal lines, not horizontal baselines | "diagonal type", "slanted lettering", "dynamic text angle" |

## 3. THE CONSTRUCTIVIST COLOR SYSTEM

| Color | Symbolism | Hex | Usage |
|-------|-----------|-----|-------|
| **Red** | Revolution, blood, urgency, communism, passion | #CC0000 | Primary accent, wedges, stars, banners |
| **Black** | Opposition, weight, power, industrial strength | #000000 | Background, text, geometric shapes |
| **White** | Purity, space, contrast, the new society | #FFFFFF | Negative space, background, text on black |
| **Grey** | Concrete, industrial material, steel, machinery | #808080 | Secondary geometric elements, texture |
| **Yellow/Gold** | Rare accent — sun, wheat, prosperity | #FFD700 | Sparingly, for hope or harvest motifs |

**Palette Rules:**
- Never more than 3 colors in a composition
- Red is always the accent — it draws the eye first
- Black and white create the structural foundation
- Grey adds material texture without competing

## 4. BRUTALIST ARCHITECTURE: THE MONUMENTAL LANGUAGE

Brutalism emerged from Constructivism's geometric honesty but applied it to **architecture at monumental scale**. [^63^] [^66^] [^69^]

### Core Principles

| Principle | Description | Prompt Vocabulary |
|-----------|-------------|-----------------|
| **Béton Brut** | Raw concrete left unfinished — formwork marks, aggregate visible, texture honest | "béton brut", "raw concrete", "formwork texture", "exposed aggregate" |
| **Truth to Materials** | Concrete looks like concrete, steel looks like steel — no hiding, no paint | "truth to materials", "material honesty", "unadorned surface" |
| **Monumental Scale** | Buildings designed to impress through size and weight, not decoration | "monumental scale", "imposing mass", "human insignificance against structure" |
| **Geometric Clarity** | Bold shapes — rectangles, cylinders, cantilevers — expressed clearly | "geometric clarity", "bold massing", "volumetric simplicity" |
| **Repetitive Modularity** | Identical units repeated for efficiency and visual rhythm | "repetitive modular pattern", "unit repetition", "modular grid" |
| **Function Exposed** | Structure, pipes, ducts, staircases visible — architecture as machine | "exposed structure", "visible mechanics", "architecture as machine" |

### Brutalist Material Vocabulary

| Material | Visual Property | Prompt Terms |
|----------|----------------|--------------|
| **Raw Concrete** | Formwork marks, wood grain imprint, aggregate texture, water stains | "raw concrete texture", "formwork wood grain imprint", "exposed aggregate surface" |
| **Weathered Concrete** | Stains, moss, rust streaks, cracking, discoloration | "weathered concrete", "water-stained surface", "moss-covered brutalism" |
| **Exposed Steel** | Rust, weld marks, bolt patterns, industrial patina | "exposed steel frame", "rust patina", "industrial weld marks" |
| **Brick (Monolithic)** | Massive brick walls, minimal openings, repetitive bond patterns | "monolithic brick", "massive masonry", "repetitive bond pattern" |
| **Glass (Minimal)** | Small, punched windows, not curtain walls — defensive, controlled | "punched window openings", "minimal glass", "controlled aperture" |
| **Rebar Exposure** | Where concrete fails, rebar visible — decay as honesty | "exposed rebar", "structural decay", "honest deterioration" |

### Brutalist Lighting

Brutalist buildings are **sculpted by light and shadow**:
- **Harsh midday sun** creates deep shadow in recesses, emphasizing mass
- **Overcast light** flattens texture, making buildings appear even more monolithic
- **Dramatic raking light** at sunrise/sunset reveals formwork texture and surface detail
- **Interior chiaroscuro** — small windows create shafts of light in vast dark volumes

**Prompt Translation:**
> "harsh raking sunlight on raw concrete, deep shadow in recesses, formwork texture revealed by angled light, dramatic chiaroscuro, monolithic mass against sky"

## 5. COMPOSITION & FRAMING

### Constructivist Composition

| Technique | Description | Prompt Terms |
|-----------|-------------|------------|
| **Dynamic Diagonal** | Main axis at 30–45 degrees, not horizontal | "dynamic diagonal composition", "45-degree axis", "diagonal thrust" |
| **Asymmetrical Balance** | Heavy element on one side balanced by multiple small elements | "asymmetrical balance", "weighted composition", "visual counterweight" |
| **Fragmented Space** | Photomontage creates collage-like broken reality | "fragmented space", "photomontage collage", "broken reality" |
| **Circular vs. Angular** | Circles (unity, collective) vs. triangles/squares (conflict, structure) | "circle vs. angular", "geometric conflict", "shape symbolism" |
| **Text as Structure** | Typography creates the grid that holds the image together | "text as grid", "typographic structure", "type-based composition" |

### Brutalist Composition

| Technique | Description | Prompt Terms |
|-----------|-------------|------------|
| **Worm's Eye View** | Camera looking up from ground level — emphasizes towering scale | "worm's eye view", "looking up at monument", "towering perspective" |
| **Human Scale Reference** | Tiny human figure against massive structure | "human scale reference", "figure against monument", "insignificance" |
| **Symmetrical Massing** | Brutalist buildings often symmetrical — imposing, institutional | "symmetrical massing", "institutional symmetry", "imposing frontal view" |
| **Repetition Rhythm** | Identical windows/balconies create visual beat | "repetition rhythm", "modular visual beat", "patterned facade" |
| **Negative Space as Volume** | The void between masses is as important as the mass itself | "negative space volume", "void as form", "interstitial space" |

## 8. NEGATIVE PROMPTS

| Avoid | Why | Replace With |
|-------|-----|--------------|
| "soft and cozy" | Brutalism is harsh, imposing, raw | "stark honesty", "raw power", "imposing mass" |
| "pastel colors" | Constructivism uses red-black-white only | "high contrast", "symbolic minimal palette", "red black white" |
| "organic curves" | Brutalism is geometric, angular, rectilinear | "geometric clarity", "angular mass", "rectilinear form" |
| "decorative ornament" | Both movements reject decoration | "functional honesty", "unadorned surface", "truth to materials" |
| "warm lighting" | Brutalist light is harsh, dramatic, cold | "harsh raking light", "dramatic chiaroscuro", "cold institutional light" |
| "small scale / intimate" | Brutalism is monumental, collective | "monumental scale", "collective space", "imposing mass" |
