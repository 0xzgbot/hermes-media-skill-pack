# Soft Pastel Animation Lighting

## TRIGGER KEYWORDS
pixar, animated, soft pastel, pastel lighting, happy animation, cozy animation, family animation

## CORE RULES
- Use soft warm key light, pastel bounce, gentle gradients, and rounded shadow transitions.
- Keep eyes expressive and readable, but avoid over-large uncanny proportions unless requested.
- Use clean color separation between character, wardrobe, and background.
- Preserve believable material cues even in stylized animation.

## PROMPT ARCHITECTURE
- Pair animation style with physical lighting: warm window key, sky-blue fill, peach rim, soft contact shadows.
- Keep the prompt optimistic and tactile: soft fabric, glowing dust, warm stone, clean sky, luminous skin.
