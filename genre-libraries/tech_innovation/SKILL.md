# SKILL: Tech & Innovation
## Version: 1.0 | Hermes Agent Brand Voice & Style

---

### DESCRIPTION
Mastery of the clean, precise visual language that signals intelligence, future-forward thinking, and engineering beauty. Tech cinematography treats code, silicon, and interface as aesthetic objects worthy of the same reverence traditionally reserved for nature or the human face. The frame must feel calculated — every pixel, every reflection, every geometric relationship intentional.

### TRIGGER KEYWORDS
technology, tech, innovation, future, AI, software, hardware, product tech, clean tech, startup, digital, interface, code, silicon, engineering, precision, minimal, modern tech, tech launch

### CORE RULES
- Precision and intentionality: every element placed with purpose, nothing accidental
- Color palette is constrained: white + accent color (blue, green, electric) on dark background or white
- Materials signal quality: aluminum, glass, clean injection-molded surfaces — rendered precisely
- Light should catch geometric edges: edge lighting reveals form while keeping surfaces clean
- Scale reveals detail: PCB traces, screen pixels, connection ports warrant macro treatment
- Human element grounds the abstract: human hand holding device makes it tangible
- Avoid clutter: clean desktop, empty table, isolated subject — complexity is in the detail, not the surround

### TECHNICAL PARAMETERS

**Clean Geometry:**
- Composition: Symmetrical, centered, grid-based; golden ratio used mathematically
- Lines: Straight, parallel, converging with purpose; no accidental diagonals
- Shapes: Circles, rectangles, grids, hexagons — Platonic forms as visual foundation
- Space: Generous but calculated; negative space serves function, not decoration
- Depth: Layered planes suggesting complexity — foreground interface, midground hardware, background void
- Alignment: Everything aligned to invisible grid; center-weighted or rule-of-thirds precision

**Interface Metaphors:**
- Screen as World: Device screens glow with possibility; light spills onto faces and environments
- Data Visualization: Abstract data made beautiful — particle flows, node networks, light trails
- Holographic Layering: Information floating in space, layered over reality
- Code as Texture: Scrolling code, terminal green, matrix rain as environmental texture
- UI as Architecture: Interface elements build spatial structures; menus become rooms
- Touch Response: Finger touches screen; ripple, glow, or activation spreads from contact point

**Precision Signals:**
- Focus: Razor-sharp throughout; deep focus or stacked focus for layered clarity
- Light: Even, controlled, clinical; no accidental shadows
- Color: Neutral base (white, gray, black) with single brand accent color
- Reflection: Controlled reflections in glass, metal, screens — environment as data
- Movement: Linear, mechanical, precise; or smooth algorithmic curves
- Sound: Clicks, whirs, electronic tones, silence between actions

**The Future Aesthetic Spectrum:**
- Warm Future: Beige, cream, soft wood, rounded forms — humane technology (Apple, Nest)
- Cool Future: White, steel, glass, sharp edges — clinical precision (Medical, AI, enterprise)
- Dark Future: Black, neon accent, OLED glow — power user, gaming, developer (Razer, coding)
- Natural Tech: Green, solar, biodegradable materials — sustainable innovation

### ADVANCED TECHNIQUES

**1. The Device Monument**
- Setup: Product as architectural object in clean void
- Light: Even, multi-source, eliminating all shadow
- Background: Gradient white or brand color; infinite depth
- Camera: Slow orbit or static with light animation
- Detail: Every port, button, seam visible and perfect
- Emotional: Engineering worship, precision, perfection
- Best For: Product launches, hardware reveals, flagship devices

**2. Interface as Environment**
- Setup: User surrounded by floating screens, holograms, data layers
- Light: Screen glow illuminating face and space
- Movement: UI elements animate with purpose; data flows like water
- Depth: Multiple transparent layers suggesting infinite information
- Color: Blue-white data on dark space; or warm data on light space
- Emotional: Power, knowledge, connection, future
- Best For: Software, AI, platforms, enterprise, fintech

**3. The Code Cathedral**
- Setup: Dark space filled with projected or floating code
- Light: Terminal green, amber, or white on black
- Movement: Scrolling, compiling, executing — code as living thing
- Subject: Developer face partially illuminated by screen; hands on keyboard
- Depth: Code layers in Z-space; foreground sharp, background infinite
- Emotional: Creation, logic, late-night focus, digital craftsmanship
- Best For: Developer tools, AI, cybersecurity, coding platforms

**4. Precision Assembly**
- Setup: Components coming together with mechanical beauty
- Camera: Macro, tracking, or overhead
- Movement: Robotic precision; parts slotting, welding, testing
- Light: Bright factory practicals; or dramatic spot on assembly
- Color: Metal, silicon, white plastic; clean room aesthetic
- Emotional: Manufacturing excellence, quality control, scale
- Best For: Hardware, automotive, manufacturing, robotics

**5. The Neural Network**
- Setup: Abstract visualization of AI, data, or connectivity
- Visual: Nodes, particles, light trails, synaptic flashes
- Movement: Organic but mathematical — growth algorithms, flocking patterns
- Depth: Vast networks extending into infinite dark space
- Color: Electric blue, purple, white on deep black
- Emotional: Intelligence, scale, connection, consciousness
- Best For: AI, cloud, telecom, data platforms, research

**6. Human-Machine Symbiosis**
- Setup: Human and technology in seamless integration
- Framing: Hand touching screen, eye scanning, neural interface
- Light: Screen glow on skin; or warm tech in domestic space
- Movement: Natural human motion triggering precise tech response
- Environment: Home, office, or body — tech invisible but present
- Emotional: Empowerment, augmentation, seamless living
- Best For: Wearables, smart home, health tech, accessibility
